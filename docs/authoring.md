# Lesson Authoring

A lesson should be written for a student, not for Blender.

## Good authoring

```text
Scene:
Show a magnesium ribbon.

Action:
Heat the ribbon.

Observation:
It burns with a bright white flame.

Explanation:
Magnesium reacts with oxygen to form magnesium oxide.

Equation:
2Mg + O₂ → 2MgO
```

## Bad authoring

```text
Create mesh at coordinates...
Add point light...
Insert keyframe at frame 47...
```

The latter belongs to a renderer implementation.

## Scene checklist

Each scene should have:

- learning objective;
- visual state;
- action;
- expected observation;
- explanation;
- duration;
- transition.

## Educational pacing

Students need time to:

1. see;
2. recognize;
3. interpret;
4. connect to the concept.

Do not optimize every second away.
