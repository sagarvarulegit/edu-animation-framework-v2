# Scientific Accuracy

Educational animation has two layers:

## Scientific reality

What actually happens.

## Visualization

How we choose to represent it.

These must not be confused.

## Example: atoms

A molecule visualization can show atoms as spheres.

That does not mean:

- atoms are literally colored spheres;
- the relative size is exact;
- the distances are necessarily to scale.

The visualization is a model.

## Example: chemical reactions

For chemical equations:

- verify formulas;
- verify balancing;
- verify products;
- verify conditions when relevant.

Do not allow visual animation to silently change the chemistry.

## Example: CBSE lessons

Curriculum terminology should be preserved where it matters.

If a visualization uses a simplified model, the lesson documentation should state that.
