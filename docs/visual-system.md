# Visual System

The framework should eventually define a shared visual language.

## Categories

```text
colors
typography
materials
lighting
camera
labels
arrows
equations
particles
```

## Educational priority

Visual hierarchy should generally be:

1. Main phenomenon.
2. Relevant object.
3. Explanation.
4. Supporting annotation.
5. Decorative effect.

Never allow decorative effects to overpower the phenomenon.

## 3D style

Default direction:

- clean;
- stylized;
- scientifically recognizable;
- moderately realistic;
- high readability.

Photorealism is optional, not the objective.

## Camera

Avoid motion without purpose.

Use camera movement to:

- establish;
- focus;
- reveal;
- compare;
- transition between scales.

## Labels

Labels should:

- remain readable;
- avoid overlapping objects;
- use consistent typography;
- disappear when no longer needed.
