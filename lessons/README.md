# Educational Lessons

## Overview
Subject-categorized declarative lesson definitions, scene graphs, narration scripts, and pedagogical objectives for STEM education, structured around CBSE/NCERT Class 10 curricula.

## Subdirectories & Boundaries
- [Biology Lessons](./biology/README.md): Lessons covering physiological and biological systems, including cardiac anatomy and double circulation.
- [Chemistry Lessons](./chemistry/README.md): Lessons covering chemical reactions, laboratory experiments, atomic models, and balanced equations.
- [Physics Lessons](./physics/README.md): Lessons covering optics, electromagnetism, ray tracing, and physical laws.
